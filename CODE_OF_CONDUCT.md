# Code of Conduct

OrbVis adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full canonical text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Summary

We are committed to making participation in OrbVis a respectful,
harassment-free experience for everyone, regardless of background,
identity, or experience level.

In short: be welcoming, be respectful, assume good faith, focus on what
is best for the community, and show empathy. Behaviour that harasses,
demeans, or excludes others has no place in this project.

## Enforcement

Instances of unacceptable behaviour may be reported privately to the
project maintainer at **ronny.bruska@gmail.com** with the subject prefix
`[orbvis-conduct]`. All reports will be reviewed and investigated
promptly and fairly. The privacy and safety of the reporter are a
priority.

Maintainers are obligated to follow the *Enforcement Guidelines*
described in the Contributor Covenant 2.1. Consequences range from a
private warning to a permanent ban, proportional to the severity and
pattern of the behaviour.

## Scope

This Code of Conduct applies within all project spaces — the GitHub
repository (issues, pull requests, discussions), any associated chat
channels, the Checkmk forum thread for OrbVis, and public events when an
individual is representing the project.
